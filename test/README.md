# 闭环测试套件（test/）

> 本目录由 `scripts/build-closed-loop-fixtures.py` 生成，与各模块导入器规则严格对齐，
> 并由后端常驻测试 `apps/api/tests/test_closed_loop_fixtures.py` 守护（改动导入规则或本套件都会在此暴露）。

## 文件与用途

| 文件 | 用于 | 关键约定 |
| --- | --- | --- |
| `教材-函数与导数节选.md` | 教材资料库导入（RAG 底座） | 章节标题 + 正文 + `## 习题1.1` / `## 复习参考题1.3`（课后习题提取的来源）；正文占比正常 |
| `名单-高一1班.xlsx` | 班级管理 → 批量导入 | 表头：学号（文本，保前导零）/ 姓名 / 性别；40 名学生 |
| `试卷-函数与导数单元测试.docx` | 试卷管理 → 导入试卷 | 题号 `N.`（顶层）与 `(1)`（子号），满分 `（N 分）`；共 12 个顶层题、16 个计分叶、满分 100 |
| `小题分-函数与导数单元测试.xlsx` | 学情分析 → 导入小题分 | 表头：学号/姓名/总分 + 16 个计分叶题号（含 `11(1)` 形式）；四态：数值 / 空(缺) / 缺考 / 免考 |
| `manifest.json` | 机读清单（学生数/计分叶/生成来源） | — |

## 建议的闭环走查顺序

1. **教材资料库**：导入 `教材-函数与导数节选.md` → 等待入库完成（清洗→切块→向量化）→
   在学习问答里问「函数的单调性是什么？」验证教材检索命中。
2. **知识点**：知识点页 →「从教材目录生成树」→ 得到章/节树；可在节点下增改与补「学习目标」。
3. **题库**：题库页 →「批量导入」→「从教材课后习题提取」→ 校对草稿 → 确认入库；
   按知识点/难度筛选验证。
4. **班级管理**：新建班级（如「高一(1)班」）→「批量导入」`名单-高一1班.xlsx` → 预览 40 行全部建档 →
   确认；核对班级人数为 40。
5. **试卷管理**：导入 `试卷-函数与导数单元测试.docx` → 校对拆题（16 个计分叶、满分 100）→
   为题目选择知识点分类 → 确认；下方环图显示知识点占比。
6. **学情分析**：选择班级 + 试卷 → 导入 `小题分-函数与导数单元测试.xlsx` → 核对列映射（16 叶）→
   确认成绩 → 生成/查看分析报告（红色柱得分率、热力图、知识点排行、学生×知识点、分数段）→
   导出报告 docx。
7. **教案工作台**：在「本地教案」里选学科 + 班级并新建 → 左侧模块轨确认七节顺序 →
   中栏「生成教案」选刚生成的分析报告 + 课程名称/知识点 → 流式生成 → 采用候选 →
   右侧预览从第 3 页起按模板四表排版（目标/策略同表、两行过程表头、评价四项、反思三项）→
   导出 docx（自动补齐封面与目录，目录页码与预览同源）。
8. **练习**：新建练习 → 来源选学情报告（或填写教师描述）→ 生成/选拔 → 微调 → 确认 →
   导出预览（学生卷/教师卷）+ 成绩模板 xlsx。
9. **学习问答联动**：在 `/chat` 用一句话触发各板块（如「帮我分析高一(1)班这次单元测的学情」
   「用这份学情生成一节课的教案」），或在对话里直接上传本目录文件。

## 重新生成

```powershell
uv run --directory apps/api python ../../scripts/build-closed-loop-fixtures.py
```
