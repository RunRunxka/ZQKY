# B4 shared foundation v1.3 · 完整题号

实现收口发现，v1 中“扁平化后服务决定唯一题号映射”会让教师输入的单叶题号被忽略，多叶完整题号重复套前缀，UI 新增子题已经使用完整路径。这不是可接受的静默改号。

修正精确语义：`PracticeNode.questionNo` 是教师明确的完整最终题号（例如 `16(1)`），服务原样保存并跨所有 selections 校验唯一，重复返回定位422，DB唯一约束保底。节点总 ordinal 仍按顶层/局部顺序扁平化，与题号身份分离；换序不自动改题号。固定审核快照、DOCX显示、转换原卷、XLSX映射和回流证据使用同完整题号。

DTO/字段名不变，原 v1 和已有首轮证据不覆盖。此项仍在最终稳定候选冻结前修正；相应单叶自定义、多叶 `16(1)`、换序和重复题号用例须在最终作者/独立验收中分别实际执行。

同阶段补齐 `paper_practice_confirm`：固定 practiceItem 必须一一覆盖，题号/顺序/parent映射/正式题修订/计分状态/满分/富内容与来源审核快照一致；各题固定知识点集合、修订、名称与角色也逐条相同。旧 total/leaf/KP门保留，禁止只重复引用同一源叶而冒充完整映射。共享最终迁移散列重新冻结，受影响专属测试必须重跑。
