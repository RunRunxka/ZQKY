## GSAP

根 workspace 锁定 `gsap@3.15.0`、`@gsap/react@2.1.2`，未升级现有框架。新增内部 `useEntrance`，使用作用域 ref、`useGSAP` 与更新/卸载回退；没有延后创建 tween 的事件回调。

| 场景 | 预设 |
| --- | --- |
| 首屏可见静态区块 | 280ms，淡入/上移 10px，35ms 错峰，最多 6 个顶层区块 |
| 保留挂载的业务面板首次可见 | 180ms，淡入/上移 6px |
| 公共 Modal 打开后 | 220ms，淡入/上移 8px，缩放 .985→1 |
| 手机导航抽屉 | 200ms，水平滑入；移除同目标原 CSS 入场 |

统一 `power2.out`，结束清除临时 opacity/transform。系统或应用任一减少动画即中断入场并回退样式；恢复后已显示内容不补播，再次打开弹窗/抽屉仍可入场。隐藏/被滚动容器裁切的面板不抢播。

关闭、焦点、保存和导航立即执行。流式正文、轮询数据、真实分数和矩阵单元不作为动效依赖；既有侧栏宽度过渡、推理/结果面板退出和简单 hover/focus 保留。
