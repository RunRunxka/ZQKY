# B6 教师最小试用说明

更新：2026-10-04。本材料用于本批隔离匿名样例。G3 已技术关闭；本包四例导出与实际 PDF 验收不等于真实模型教学质量、教师评审、Word/WPS 排版或原计划 B7 全部完成。当前状态以 [CURRENT_STATUS](../../../CURRENT_STATUS.md) 为准。

试用前准备匿名名单、可使用的原卷/教材片段和教师人工小题分；记录固定原卷、成绩、报告、班级、KP、教案和练习修订 ID。不要把正式学生档案放入本样例包。模型教学质量评审要另给明确 profile、模型、样例数与 token/费用预算；当前 Provider 替身只证明技术链。

## 从原卷到教学调整，再到分数回流

1. 进入 `/assessments`，依次完成名单、原卷、施测。名单明确班级和真实参测人次；原卷人工校对题面、最终题号、计分叶/满分及对应正式知识点，再确认固定卷。同一学生多个 attempt 时显式选择目标人次，不能暗中替换成最近一次。
2. 在成绩步骤上传小题分，完成映射、人工校对、预览承认和确认。预览里的缺考/缺分统计要逐类核对；修正会产生新固定成绩，原成绩保持只读。数字零分必须录为 `recorded(0)`，不能留空。
3. 从固定已确认成绩进入 `/learning-analysis`，显式选择人次，建立 ready 报告。记录固定 score/run/paper 修订。报告任务未 ready 时不要将空白画面当作“全班无问题”；看全题证据，确认单班与目标知识点，而非只看摘要百分比。
4. 从该报告进入 `/lesson-plans`，明确选择一个班级与目标 KP，创建/打开后台教案。保存后核对后台固定版本、revision ID 和保存 ACK。选择真实教材切片，必要时选择 confirmed 固定题或 reviewed 固定练习；教材引用存在仍需教师判断是否支持当前活动。
5. 点击“保存当前稿并生成 AI 候选”，等待任务结果，再逐字段阅读原稿与建议。可采用的五个完整字段为**核心素养目标、教学重难点、教学设计、教学过程、课堂练习及作业布置**。采用教学过程时应核对每个环节、design/secondary 和分钟预算；这是完整字段替换，不是任意局部拼接。
6. 只勾选确实采用的字段，再明确应用；未选字段应保留。教师六字段**课题、总课时、本节课、课型、其他课型说明、教学反思**由教师控制。生成成功或候选存在都不自动改正文、审核题目或发布课堂练习。应用后核对当前新固定版本；历史只读，可明确复制为新编辑、撤销/重做并另存新版本。
7. 在 `/practices` 建立针对练习，核对正式题修订、KP 覆盖、题型/满分、题号及缺口，保存草稿后由教师审核。缺题需走现有题库人工审核/正式确认后再选择，不把模型建议或教案 `exercises` 字符串当正式题库对象。审核版固定后导出学生 DOCX、教师 DOCX；学生版不含答案，教师版缺答案应有标识。
8. 由该固定 reviewed 练习转换新施测，核对真实名单、固定卷叶映射，生成该施测专属成绩模板。课堂施测后由教师填写新小题分，再走校对/承认/确认得到新成绩和新 ready 报告。比较新旧固定事实；原报告、旧教案和练习历史不应改写。这里没有 AI 自动改卷或掌握概率推断。

每一步记录固定修订与检查结果；若来源失效、保存未知或版本冲突，先处理可见错误再继续，不能以旧成功 toast 当作当前 ACK。

## 解释学情时保留的边界

| 成绩状态 | 教师理解 |
| --- | --- |
| `recorded`（含 0） | 有教师确认的分数；零分是有效记录 |
| `missing` | 小题分缺失，信息不全；不能补零 |
| `absent` | 缺考人次；不能当作记录零分 |
| `exempt` | 免考人次；不能当作满分或零分 |

`any_loss_v1` 的“需巩固”只指**本次固定成绩所见失分**，不是长期能力标签或诊断错因。分母是该 KP 至少有一格 recorded 的被选唯一学生，零分母是 `null`；不能写成 0% 或 100%。`needsCount`、`incompleteCount`、`noEvidenceCount` 可以重叠，不能相加当互斥人数。综合题失分只提供关联线索，不能凭关联 KP 编造学生哪一步出错。历史成绩没有班名时保留“该成绩未记录班名”，不能借当前名单重写历史。

RAG-REL 仍 OPEN。正例、边界、范围外、无依据分别查看；相似分数或引用结构合法都不能替代教师相关性判断。生产 ImmutableSource 可以复用已验证不可变缓存，不能声称每次调用均重新读取磁盘 bytes。

## 本地、后台、未知结果和冲突

默认本地稿使用本机草稿和规则填充；后台教案有 document ID、固定 revision 和保存 ACK，历史正文也有固定身份。本地保存不是后台 ACK。现有大纲区仍可能显示泛化“本地工作模式/草稿保存在当前浏览器”（OBS-LP-MODE-LABEL）；**以后台固定身份及保存 ACK 判断模式**，不能用该泛化文案判断后台保存是否成功。

保存、创建、导入、生成或采用出现 unknown 时，保留首次完整原包和提交标识，按界面“重试原保存包/创建包/导入包/生成包/采用包”处理；不要改包换标识来猜结果，不把 unknown 当失败零写入。恢复缓存读取失败时保留原字节并暂停，先备份当前内容。

409 版本冲突须人工看本机稿与最新后台稿差异。界面可先“读取后台最新版本”，再明确“采用后台基线，保留本机正文”或“明确恢复后台正文”；没有自动合并。选择前备份当前稿，另存后核新 ACK。历史复制期间若教师已编辑，保留新稿与复制意图，重新明确复制才替换；复制本身是新编辑，可撤销。

离开有未保存内容时，按当前真实意图选择保存后离开、保留恢复稿后离开或明确放弃。放弃会恢复可信基线并撤销被放弃会话的后续写能力；若导航没有完成，新的教师编辑仍可重新保存。已经发出但结果未知的操作不能被“放弃”虚假撤回。

## 导出和备份

先核当前后台固定版本，再用“导出教案 → 导出 Word”或“导出 PDF → 打开打印窗口”。日常浏览器打印选择另存为 PDF、关闭浏览器页眉页脚，并逐页对照当前源标签；实际 PDF 文件才算保存完成。打印期间使用冻结快照且编辑锁定，结束后再编辑。历史版本导出只代表所打开的固定历史，不应误认为最新版本。

本包 [四例与逐页清单](PAGE-REVIEW-v1.md) 有真实 DOCX/PDF、完整正文和来源 manifest。PDF 已逐页实际检查；Word/WPS 排版待教师实际打开，按清单核对每一页并填应用版本、页码和意见。Word 原模板页面与 PDF A4 不同，页数不必相同；长二次备课窄栏可能产生续页和中栏空白。Word 现有来源在下载文件名及 manifest 映射中，PDF 在每页页脚。

教案“备份草稿”JSON仅用于该教案内容恢复。完整数据保护使用现有**四库+受管资产的离线一致性备份**，与 JSON 备份分开；安排维护窗口、核对清单/散列并在隔离数据根验证恢复，不运行正式迁移或正式 Qdrant 操作。已有恢复证据的 SQLite/Blob 真恢复与 Qdrant 替身分列，本说明不提供本批未授权的生产部署命令。
