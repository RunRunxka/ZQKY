三、G5-E：缓存清理使用本次结果，不能使用历史result

现行 DocumentsPanel.tsx:66/70 用 recoveryKind==='cleanup' 下的operation.result决定打开文档；useLessonOperation.ts:51–52 对明确成功和明确失败均会进入cleanup。共享useFrozenSubmission只在成功时写result，新请求/失败不清旧值。

实际首败序列：当前后台教案→创建等待期间编辑→第一次创建成功first-created→取消离开继续编辑→第二次创建明确422→removeItem失败→恢复存储点击“重试创建操作恢复缓存”。当前错误跳到first-created。正确行为是只清理第二次失败包、保持当前教案/正文/选择，不发第三次create，不将第二次失败说成成功。正文丢失未被本次审查证实，不夸大影响。

设计要点：清理恢复记录绑定本次operationId/submissionId、contextKey/loadGeneration和明确结果类型。success才能携带本次receipt；failure不能暴露前一success receipt。发送前write失败和结果unknown仍保持原包身份，不与cleanup合并。

pseudocode（名字可适配现有实现，语义不可删）：

type CleanupOutcome<T,R> =
  | { type:'success'; operation:FrozenSubmission<T>; receipt:SubmissionReceipt<T,R> }
  | { type:'failure'; operation:FrozenSubmission<T>; error:ApiError };

async run(...) {
  const session = freeze(contextKey, ownLoad);
  let sentOperation = null;
  // 在现有submit回调捕获实际本次operation，不能用旧render的frozen推断。
  const receipt = await existingSubmit(async operation => {
    sentOperation = operation;
    persistExactOriginalPackage(operation); // 失败时HTTP=0
    return existingSend(operation);
  });
  if (!sameSession(session)) return receipt;
  const outcome = receipt?.current
    ? {type:'success', operation:receipt.operation, receipt}
    : isExplicitNonRecoveryFailure(error)
      ? {type:'failure', operation:sentOperation, error}
      : null;
  if (outcome) try { clearOwnRecoveryPackage(); }
  catch (cause) { recoveryFailure = {kind:'cleanup', session, outcome}; }
  // unknown或发送前失败保留原有恢复逻辑、原身份，不伪造明确结果。
}

async retryOperationCache(kind) {
  const failed = captureOwnedRecoveryFailure(kind); // 本次结果+原会话
  if (!mayRetry(failed)) return;
  const repaired = await existingCacheRetryWithReadBack(failed);
  if (!repaired || !sameOwnerAndSession(failed)) return;
  showCacheCleanupNotice();
  if (failed.kind==='cleanup' && failed.outcome.type==='success') {
    // 校验receipt.operation身份；仍走现有离开保护，不强制丢弃新编辑。
    await existingOpenDocument(failed.outcome.receipt.result.lessonPlanId);
  }
  // cleanup+failure仅清缓存与解锁；不能打开其他教案。
}
