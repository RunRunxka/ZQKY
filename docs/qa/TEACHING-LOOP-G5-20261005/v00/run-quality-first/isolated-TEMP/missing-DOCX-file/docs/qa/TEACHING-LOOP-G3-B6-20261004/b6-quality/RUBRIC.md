# 匿名教学质量评审量规

本表是人审准备材料。离线Provider回复为手写替身；JSON合法、引用完整及字段保存的技术PASS不能变为教学质量PASS。评审人姓名或代号、日期、原文位置和理由由真实教师填写，当前全部 teacher_review_pending。手写 expected 是独立QA依授权 any_loss_v1 规则列举的数字，未冒充真人教师评审，也未调用生产聚合或用生成候选反填预期。

## 先判断硬失败

错来源或修订、错误分母、把0分母写0%或100%、把missing/absent/exempt当零分、把重叠计数相加为互斥人数、泄漏学生身份、虚假引用、改非法/教师字段、总分钟或整数阶段不符、把课堂字符串当自动发布的未审核正式题，均记 hard_failure，不能被平均分抵消。结构硬约束使用真实API、白名单和固定正文核验；语义硬失败仍须教师阅读输出。综合题关联失分不等于具体错因，也不是长期掌握概率。

## 教师评分

各维0～3：0=不能用于课堂；1=明显问题，需重写；2=基本可用，需教师修改；3=依据充分且在本班可实施。未观察留空，不能给替身自评；不自动合计为通过。

| 维度 | 教师阅读重点 | 记录依据 |
| --- | --- | --- |
| 学情事实解释 | unique selected学生及显式attempt；有效recorded分母；零分母null；needs/incomplete/noEvidence重叠 | expected、逐学生表、匿名wire、输出原文位置 |
| 教材支持与相关性 | 当前片段是否支持具体论断；边界、范围外、缺证明是否如实说明；不能只看引用存在或相似分数 | 固定片段文本/坐标/SHA与原文对照 |
| 目标知识点覆盖 | 明确单班所选KP均被活动覆盖，综合题不臆造某步骤错误；不引入未选班 | case固定映射、各环节KP alias |
| 活动与课堂检测 | 活动有可观察操作和出口检测，检测能区分待核实问题；原题仅文本投影不猜图片 | 过程design/secondary、activity/check和题修订 |
| 时间与可实施性 | 5分钟是否现实；40/45分钟整数分配是否留操作和反馈时间；不能用形式四阶段替代可行性 | 预算分钟与教师班级经验 |
| 教师控制及保持 | 仅五完整字段可选择；六教师字段及未选内容不变；建议仍待教师审核 | 原稿、选择字段、应用后完整正文 |
| 内容准确与可解释 | 没有无依据知识、错误推导或能力标签；术语和指令让教师读懂 | 原文引用与教师纠正建议 |
| 后续练习与反馈 | 明确题库缺口；候选练习文本与已审核practice对象区分；教师分数回流不是AI改卷 | coverageGap、固定题/练习修订与回流材料 |

RAG-REL保持OPEN。本包选证据结构核验不是新的检索拒答验收。C10正例、C11窄边界、C12范围外、C13缺请求依据分别评价；C15 noEvidenceCount 是学生成绩证据缺失，不能与教材无依据混同。

## 真人结论规则

先列 hard_failure 与证据，再逐维打分并写修改建议。即使全部结构检查通过，也保持 teacher_review_pending，直到有真实教师反馈。live_run另需明确 profile、模型、样本数和token/费用上限；缺输入不执行。质量结论不代替WPS/PDF排版、正式迁移或压力验收。
