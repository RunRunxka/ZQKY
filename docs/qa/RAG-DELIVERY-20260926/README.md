## 9. 已知限制（交付给用户的实话）

1. **生成非确定**：同一题新鲜运行可能一次给摘录、一次拒答（本批 NEW-MATH 由 v5 拒答变为 v6
   摘录）。只有同一进程 600 秒 TTL 内的重放可复现；跨进程/重启后会重新推理。
2. **相关性由小模型判定**，仍有弱相关引用（例：数学题第 3 条 `B={0,1}` 与题目无关）。
3. **教材 OCR/转换噪声**仍可能进入摘录；逐字符一致只证明「等于教材」，不证明「教材正确」。
4. 摘录**不给出答案本身**（如数学题不会输出 `A={1,2}`），这是 excerpt 模式的边界。
5. 索引空间仍含已知的正文污染残余（P8D 判定 FAIL 维持）。
