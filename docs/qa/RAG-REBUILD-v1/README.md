### 3.1 来源可复现性的更正（独立验收 D5）

迁移当时读取的 `F:\人教版教材\markdown` 目录**现已不含任何 `.md`**（外部流程变动，非本项目所为）；
同目录下 `F:\人教版教材.zip`（1.45 GB）内含 **58** 册 markdown，其中 57 册与已迁移文档登记的
`original_file_sha256` **逐字节一致**（A1 独立比对）。因此：

- 早前那次迁移结果**可核验**（与归档散列一致），但**不可从原目录路径复现**；
- 迁移脚本已新增 `--source-zip`：从归档只解 `.md` 到**本次运行独占**的暂存目录再走同一流程，
  现在能识别 **58 册**（此前从目录只能识别 57 册）。
- **就此更正本文件早前的说法**：「该册只有 OCR JSON 无 markdown」只对**当时的目录**成立，
  对归档不成立——归档里该册有 md。
- 并发提醒：暂存目录必须每次运行独占。实测两次迁移共用同一暂存目录时，文件会被互相截断
  （58 册瞬时只剩 56 册）；脚本已改为按进程号派生目录，并支持 `--staging` 显式指定。

**年级归属是规则推断**（必修→高一、选修/选择性必修→高二），需教师在教材管理页确认后才参与检索；
这是如实标注的推断，不是自动认定的教学口径。

### 3.2 索引范围口径更正（独立验收 P2）

早前的文档写「只索引 `body` 区」**不准确**。实现是：**全部块都写入向量库**（含 `region='exercise'`），
检索时用 Qdrant `filter` 限定 `region='body'`。实测 57 册那一代 collection 9,462 点 = 7,681 body + 1,781 exercise。
检索行为层面成立（按 region 过滤后每册点数等于 body 块数），但措辞已按实现订正。

## 5. 已知质量边界（不得表述为"质量通过"）

1. **`chapter_path` 章节归属不准**：真实教材（PDF→markdown 转换产物）的标题层级不规范，
   部分块的章节路径被挂到相邻小节（例：`探究弹簧弹力与形变量的关系/滑动摩擦力`，实际应在第 3.2 节摩擦力下）。
   **行号定位是准确的**（引用文本与不可变原文逐字节一致），错的是章节标签。
   影响：引用展示的章节名可能误导；邻块扩展的"不跨章节"判定比预期更保守。
2. **人工教学质量 `not_run`**：知识点概括的"教学正确性"没有人工评审，
   自动化只能证明「证据可核验、引用可追溯」，不能证明「讲解正确」。
3. **检索相关性只做过抽样目视**：物理三问的证据落在正确小节，数学/化学/生物未逐条核对。
4. **AI 整理的真实模型输出形状未联调**（单测为替身）。
5. 单册文本超过租约（90 秒）的任务才会失权；实测单册远低于该值。
