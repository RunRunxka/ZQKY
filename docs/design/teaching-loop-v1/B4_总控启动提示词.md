2. 人次必须教师明确选定。同学生 one attempt/student；多次作答不偷选最高/最新、不合并。返回可选择人次及其 frozen 身份/班级/出勤，若违反唯一性给可定位 422。历史学生改名/转班/补考、知识点更名/归档、成绩 active 变化，都不能改变旧报告内容。
3. 对每个被选人次×知识点，取关联固定计分叶与其所有四态单元：
   valid = recorded（包括有效 0）；loss = valid 且 scoreUnits < maxScoreUnits。
   loss>0 → needs_consolidation；
   valid=0 → no_evidence；
   loss=0 且 0<valid<expected → incomplete；
   loss=0 且 valid=expected>0 → full_credit。
   missing/absent/exempt 不计有效，不能补 0。报告同时列每种状态数和信息完整性；有失分仍可 informationIncomplete=true。
4. 每班每 KP 返回 selectedStudentCount、validStudentCount、needsConsolidationCount、informationIncompleteCount、
   noEvidenceCount、fullCreditCount 及 consolidationRatio={numerator,denominator,value|null}。
   分母是该 KP 至少有 recorded 的有效学生人数；分母0返回 null，显示暂无有效依据。
   信息不全是独立标记，可以与 needsConsolidation 重叠，不能声称这些人数互斥后强制相加等于班级人数。
5. 同题多 KP 同时成为事实依据，显示“综合题失分关联，具体错因待教师确认”；不分摊失分，不根据分数猜错因，不把 KP 分组合计重新加成试卷总分。学生试卷总分复用 T60 完整 recorded 才有 totalUnits 的规则。
6. 存不可变输入 snapshot、规则版本/hash、结果和全部题目证据（不仅失分项）。证据定位到 scoreRevisionId、paperRevisionId、
   participantId、完整题号/itemId、满分、原得分/四态、知识点固定修订/名称、原题富内容及来源坐标/资产。
   reader 读取失败明确错误，不退成空证据；不得用只返回未归属块的旧 DTO 截断原题。
7. 报告 ready 后输入/结果/evidence 在服务和 DB 触发器层不可 UPDATE/DELETE。教师备注独立追加表，不覆盖事实或原成绩。
   相同固定输入 canonical hash 幂等重用结果；明确重新分析仍可追溯相同输入，不制造依赖 active 的新结论。
8. 准备 200学生×100叶的非模型分析基线，记录设备、样本、准备用时与纯分析时间；目标按 v2 为3秒，实测超目标先定位瓶颈，不能删证据或减少矩阵格数取巧。

六、T80：已确认题选题、审核、富 DOCX 和施测回流

1. 只从 ready 报告选择目标 KP；约束至少明确题量/题型/难度或未知处理/原题排除/重复排除。
   选题只用 T50 正式已确认固定 questionRevisionId，排除原题与权威重复，稳定排序按未覆盖目标数、约束匹配、questionId。
   一题多 KP 只占一个题位；返回真实候选、覆盖和缺口，不自动放宽题型/难度/目标，不暗中调用模型补题。
2. 缺题时教师主动复用既有 question-generation-jobs → needs_review → 人工保存 → 审核 → 正式确认链。
   草稿/AI候选不得直接进入审核练习。模型冻结/六态/取消/retry沿用现行公共协议，姓名/学号/人员 ID 不发模型。
   本批不创建独立“练习自动出题引擎”，真实 AI 教学质量未验须如实标注。
3. 练习草稿支持人工增删/换序、固定正式修订选择、题号/父子结构/计分叶/满分/KP复核，expectedRevision CAS。
   审核在 PublicationCoordinator 内重新核题目/KP身份、修订、同学科/活动状态，数据库读取和短事务持锁；
   资产/富内容验证先在锁外完成，提交前用身份/hash核其仍匹配。固定全部正式题富内容、材料、答案解析、KP修订/名称/选题理由。
4. 审核后的 practiceRevision 和 items/links 不可变，直接插入已审核或增删改封存子项也须被 DB 拒绝。
   修改审核版建立新草稿修订，旧练习/导出/施测保持旧内容，不随题库更新、知识点更名或当前 active 改动。
5. 导出严格复用 T10 render_rich_document 与受管资产。学生/教师 DOCX 内容投影分开：
   共同材料按真实材料身份/内容只出现一次，题号/计分叶顺序正确，表格/图片relationship/OMML/LaTeX保真；
   学生版没有答案、解析、教师说明；教师版有答案/解析，未提供则明确标注。
   缺资产/错误散列/非法owner/公式不支持或转换失败明确阻断或可见问题，不能生成丢内容的“成功”卷。
   渲染失败不发布 export_artifact；同submission或同固定输入重复不会产生混淆身份的产物。
6. 学生版泄漏检查须解包整个 DOCX 的 XML、relationships、headers/footers/comments/customXML/嵌入对象引用等，
   验证无测试答案/解析标记与教师专属块，不能只检查 document.paragraphs。图片关系真实可读、受管散列正确。
   Word/WPS 真实打开中文、长题干、表格、图片、公式样本验证排版；未能打开写 not_run，XML通过不冒称实际版式通过。
7. 成绩模板用 fixed practiceRevision/paperRevision 与计分叶身份；包含文本学号（前导零）、姓名、出勤、每个叶列，
   附固定修订与完整题号映射说明。不把公式算分结果当作原始成绩，不在模板暗补 0。
8. 转换仅接受已审核固定 practiceRevisionId。新纸卷固定 source_practice_revision_id 并复制真实计分叶/KP快照，
   仍通过确认卷总分/结构/来源/知识点闸门。用现有 T30 服务端学生/班级归属核验、显式非空参测、日期/人次规则冻结人次；
   不信任客户端姓名学号，不覆盖旧归属。纸卷创建/确认、施测、人次、转换映射、submission收据在教学库同一事务完成。
   同包重放返回同 paperRevision/assessment/participants；异包同submission 409，故障零半卷/半施测，跨practice引用拒绝。
9. 回流直接进入现有 T60：新施测→成绩上传/映射/校对/承认/确认→新 scoreRevision→新的 T70 analysisRun。
   保存 practiceItem→paperItem→scoreCell→analysisEvidence 的可追溯映射，旧原报告不覆盖，不能只做下载文件声称闭环完成。
