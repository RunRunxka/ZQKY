## 10. S7：视觉、动画、可访问性与响应式逐项验收

每个交互同时验收静态起点、过渡过程、最终状态。以参考源码为准记录触发、属性、起止值、时长、缓动、挂载/卸载、退出、打断、焦点和减少动画。

已知参考例子：输入区宽度约 650ms，部分弹出层 160ms，过程展开 300ms；这些不是所有动画的通用时长。不同缓动保留，原版无动画处不加装饰动画。

必须覆盖欢迎到首次发送、侧栏/右面板宽度、菜单/弹窗/抽屉、输入框高度、标签增删、发送/停止、工具过程、追问与结果、设置折叠/导航/保存、按钮悬停/按下/禁用/加载/提示浮层。

连续点击、快速关闭再打开、进入/退出过程中切换会话、生成中跳页、浏览器返回、停止立即重试均能中断并收敛到正确状态。隐藏内容不可聚焦；Escape、点击外部、焦点回归的规则与参考和可访问性一致。使用 prefers-reduced-motion，并保留本地减少动画设置的现有优先级与持久化。

在 **1440×900、1920×1080、390×844** 下逐页检查：横向溢出、长标题/题干/选项/文件名、长代码/公式/表格、输入键盘、滚动容器、固定输入区、按钮、抽屉和弹窗。确认可见和可达，不能用全局 overflow-hidden 掩盖内容丢失。

对参考与目标使用相同视口和可比内容截图，排除浏览器外框，说明品牌与 MCP/Skills 迁移等有意差异。重点页面需要实际视觉查看，不只自动比尺寸。

动态证据包括起始/中间/结束帧及可用录像。至少检查关键动作整段播放或连续帧，确认发生了目标动画，而非截图已到终态。报告“检查了静帧”与“检查了整段录像”的实际边界。仅断言 animationName/duration 或仅记录 token 不算动态验收。
