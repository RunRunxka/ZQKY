# 项目指南（最小骨架版）

> 唯一目标与稳定决定。历史完整产品的目标与红线归档于 git tag `archive-full-v1-20261011`
> （`git show archive-full-v1-20261011:docs/PROJECT_GUIDE.md`）。

## 1. 目标

**对话优先的教学 AI 工作台**：一个干净的对话界面承载全部教学 AI 能力；业务能力
（教学闭环）随重建作为 Agent 工具在对话中逐项回归——**先对话，再长业务**。

- Agent 是编排层：LangGraph 内嵌 FastAPI，工具表按业务重建逐项扩展；
- 对话是一等界面：会话、流式、附件、中断确认卡（写操作必须经教师确认）；
- 模型配置独立于业务：连接/档案/目录/授权（含 OAuth 受管认证）。

## 2. 稳定决定（红线延续）

- **AI 只进候选**：AI 产出必须经教师确认后才落库；Agent 写操作经中断确认卡。
- **学生个人信息不进模型**：姓名/学号/人员 ID 不进入任何模型上下文。
- **凭证边界**：API Key 只存后端 `.env` 经 SecretStore 显式注入；LangChain 官方包
  构造前断言 `OPENAI_API_KEY`/`ANTHROPIC_API_KEY` 未在进程环境出现。
- **单一业务后端**：FastAPI（`apps/api`）；前端不直连模型、不起第二套后端。
- **视觉基准**：`/chat` 是默认主页；品牌蓝色与既有排版 token 不变。
- **数据保护**：不覆盖用户正在编辑的会话；读取失败不降级为空数据。
